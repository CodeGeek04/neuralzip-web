# Product

## Register

product

## Users

People who want to make a text file smaller and restore it later without understanding machine learning. Developers also need an installable Python library, predictable command-line tools and reproducible evidence. Most visitors arrive from a social post, use a laptop in an ordinary bright room, and want to try a sample before installing anything.

## Product Purpose

Neurzip makes exact text compression approachable. Encoding produces one portable archive. Decoding restores original bytes and verifies them. The browser and Python library share a format. Every nonempty archive stores learned model weights and an arithmetic-coded stream. Explain training time and model overhead directly. Success means someone can complete a round trip without reading a research paper.

## Brand Personality

Clear, precise, quietly inventive. Friendly language, concrete results and truthful comparisons. Show the file, its size, the work happening and the verified result.

## Anti-references

Avoid a generic AI landing page, invented performance promises, decorative dashboards, endless feature cards, terminal-only onboarding, dramatic hacker imagery and excessive settings.

## Design Principles

1. Put a working encode/decode tool before marketing.
2. Make every action reversible and every result understandable.
3. Keep files on the device and explain the selected compression method.
4. Offer samples before demanding an upload or installation.
5. Make the simple path obvious and expose research controls progressively.

## Accessibility & Inclusion

Aim for WCAG 2.2 AA: keyboard operation, visible focus, labeled controls, readable contrast, live progress announcements, reduced-motion support and a responsive layout down to 320px. Drag and drop always has a normal file-input alternative. File contents render as text, never HTML.
